# Towards an integrated framework for developing blockchain systems

Paper ID: `INTEGRATED_BLOCKCHAIN_ISDM_FRAMEWORK_2024`

This bundle encodes the integrated blockchain ISDM framework as a DSR-OKF paper package. The core contribution is not a domain-specific blockchain application but a method/framework artifact: an integrated set of blockchain-development method fragments grouped by development process, roles, and modeling outputs.

## Files

- `index.md` — paper metadata
- `dsr.md` — DSR concepts and framework elements
- `evidence.md` — paraphrased evidence items with PDF page references
- `relations.yaml` — typed relations between problems, requirements, principles, features, artifacts, evaluations, and output knowledge
- `aliases.yaml` — retrieval aliases
- `graph.json` — graph-friendly representation of nodes and edges
