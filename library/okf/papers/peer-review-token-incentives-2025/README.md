# Blockchain-based token system for incentivizing peer review: A design science approach

DSR-OKF bundle for the peer-review token incentive paper.

This bundle is an unreviewed OKF draft extraction for the DSR chatbot. It captures the paper's peer-review incentive problem, DSRM process, formal design principles, design features, blockchain token artifact, prototype, evaluation, output knowledge, and limitations.

## Files

- `index.md` — paper metadata
- `dsr.md` — DSR concepts
- `evidence.md` — evidence items with page and section references
- `relations.yaml` — typed links among concepts
- `aliases.yaml` — retrieval aliases
- `graph.json` — graph rendering helper

## Scope notes

The paper explicitly labels **Incentives**, **Flexibility**, and **Trust** as design principles. It explicitly maps those principles to **Tokenization**, **Immutability**, and **Decentralization** as design features. More concrete implementation concepts such as soulbound tokens, fungible tokens, Polygon smart contracts, off-chain storage, and batch reward processing are extracted as artifact-level design features.
