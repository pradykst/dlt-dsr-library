## Extraction summary

This bundle focuses on the paper's trust-enabling design knowledge for inter-organizational capacity exchange:

- behavioral uncertainties and transaction-cost problem framing
- 19 meta-requirements across the transaction lifecycle
- 6 formal design principles: tender signaling, identity signaling, authority/fairness, incentives, screening, reputation
- 16 design features grounded in the smart-contract implementation
- blockchain prototype with tender, identity, and reputation smart contracts
- ex-ante design-principle evaluation and ex-post pretest/posttest experiment
- output knowledge that blockchain does not automatically create trust without correct design-principle implementation
