# Paper bundles

Each paper directory must contain exactly:

```text
README.md
index.md
dsr.md
evidence.md
relations.yaml
aliases.yaml
graph.json
```

All machine-readable records use the frozen `okf-dsr-v1` schema documented in [`docs/OKF_SCHEMA.md`](../../../docs/OKF_SCHEMA.md). The current bundles are OKF drafts and remain unreviewed until explicit human review metadata is recorded.
