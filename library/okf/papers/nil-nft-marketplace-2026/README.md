# Designing a fair and inclusive digital asset-based name-image-likeness marketplace

DSR-OKF bundle for the NIL NFT marketplace paper.

This unreviewed OKF draft extraction captures the paper's fairness and inclusiveness problem, inclusive-meritocratic fairness criterion, NIL marketplace design requirements, design principles, NFT marketplace design features, DApp prototype, evaluation, design theory, and limitations.

## Files

- `index.md` — paper metadata
- `dsr.md` — DSR concepts
- `evidence.md` — evidence items with PDF page and section references
- `relations.yaml` — typed links among concepts
- `aliases.yaml` — retrieval aliases
- `graph.json` — graph rendering helper

## Scope notes

The paper explicitly labels five design requirements: **Inclusiveness**, **Meritocratic Allocation**, **Market Thickness**, **No Congestion**, and **Market Safety**. It explicitly labels three design principles: **Plausible Events**, **Market Royalties**, and **Blockchain-Based Marketplace**. It explicitly labels two design features: **Random Minting** and **Market Exchanges**. Additional implementation-level features such as NFTs, smart-contract royalty distribution, wallet transactions, and DApp interfaces are extracted as artifact-level design features.
