# Design requirement R6.3: Backup, recovery, and support

The user experience should also include exception handling, for instance, if a device that stores the customer data is lost or stolen. In this case, either there must be a built-in recovery mechanism, or the customer must be able to ask for rapid support. Thus, we also added such backup, recovery, and support features to our requirements.

## Source paper

This design requirement is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
