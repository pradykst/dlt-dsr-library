# Design principle DP3: Route users to their private network

Provide the system with a module that provides only bandwidth to the user while users are routed to their private network even if their identity is known, in order to prevent users from conducting fraudulent actions.

## Source paper

This design principle is proposed by [An Architecture Using Payment Channel Networks for Blockchain-based Wi-Fi Sharing](../papers/wifi-sharing-payment-channels.md) (Christian Janiesch, Marcus Fischer, Florian Imgrund, Adrian Hofmann, Axel Winkelmann, 2023).
