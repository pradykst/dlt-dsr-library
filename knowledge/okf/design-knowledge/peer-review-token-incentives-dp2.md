# Design principle DP2: Flexibility

Support functionality that is customizable to the needs of stakeholders, so that different outlets can motivate reviewers with different reward types (e.g., recognition vs. monetary reward), consistent with expectancy theory.

## Source paper

This design principle is proposed by [Blockchain-based token system for incentivizing peer review: A design science approach](../papers/peer-review-token-incentives.md) (Chad Anderson, Pratiksha Shrestha, Suman Bhunia, Arthur Carvalho, Younghwa Lee, 2025).
