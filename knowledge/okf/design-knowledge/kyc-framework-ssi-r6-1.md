# Design requirement R6.1: Low complexity

The eKYC process must be convenient, so that customers are not discouraged from registering at the new bank. It is only when the eKYC process is fast and simple for the customer that it can provide high security and acceptance. Thus, low complexity is a major requirement for user experience.

## Source paper

This design requirement is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
