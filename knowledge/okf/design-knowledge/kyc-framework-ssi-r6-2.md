# Design requirement R6.2: Availability of different user interfaces

The variety of devices on which a customer can perform the eKYC process must be respected. Mobile phones are often the customers' preferred option, but support for web apps is also necessary in many circumstances. Thus, the availability of different user interfaces is important.

## Source paper

This design requirement is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
