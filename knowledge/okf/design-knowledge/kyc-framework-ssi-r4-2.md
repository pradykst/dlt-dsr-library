# Design requirement R4.2: Validity checks

If banks do not comply with the regulations, there can be heavy fines, so it is important to establish trust in the KYC process. The documents must be tamper-proof, so a further requirement is that validity checks of these documents are feasible.

## Source paper

This design requirement is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
