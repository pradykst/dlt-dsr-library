# Design principle DP1: Confidential storage with proof of integrity

Store the sensitive data in a manipulation-resistant storage exclusively with the information provider and instantly create a manipulation-resistant proof of integrity for the information recipient, so that neither manipulation nor leakage occurs.

## Source paper

This design principle is proposed by [And No One Gets the Short End of the Stick: A Blockchain-Based Approach to Solving the Two-Sided Opportunism Problem in Interorganizational Information Sharing](../papers/short-end-opportunism-sharing.md) (Lukas Florian Bossler, Arne Buchwald, Kai Spohrer, 2025).
