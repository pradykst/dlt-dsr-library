# Design requirement DR10: High software uptime and availability

High software uptime and availability, since blockchain does not scale as easily as other technologies, so data processing via blockchain should be reduced to a minimum.

## Source paper

This design requirement is proposed by [From ambivalence to trust: Using blockchain in customer loyalty programs](../papers/ambivalence-trust-loyalty.md) (Manuel Utz, Simon Johanning, Tamara Roth, Thomas Bruckner, Jens Strueker, 2023).
