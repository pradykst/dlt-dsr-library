# Design requirement DR8: Intuitive user interface

An intuitive user interface, so users should not have to deal with the technical details of blockchain technology when monitoring generation and consumption data or managing their GET and sustainability bonuses.

## Source paper

This design requirement is proposed by [From ambivalence to trust: Using blockchain in customer loyalty programs](../papers/ambivalence-trust-loyalty.md) (Manuel Utz, Simon Johanning, Tamara Roth, Thomas Bruckner, Jens Strueker, 2023).
