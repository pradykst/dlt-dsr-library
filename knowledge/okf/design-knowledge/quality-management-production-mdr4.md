# Meta-requirement MDR4: Integration of object types and events

The system should allow the integration of object types and events.

## Source paper

This meta-requirement is proposed by [Digging for Quality Management in Production Systems: A Solution Space for Blockchain Collaborations](../papers/quality-management-production.md) (Norman Pytel, Benedikt Putz, Fabian Boehm, Axel Winkelmann, 2022).
