# Design principle DP3: Differentiate aims of data processing

Differentiate the aims of data processing, since different anonymization techniques allow proving data integrity or computational integrity.

## Source paper

This design principle is proposed by [Yes, I Do: Marrying Blockchain Applications with GDPR](../papers/yes-i-do-gdpr.md) (Benjamin Schellinger, Fabiane Voelter, Nils Urbach, Johannes Sedlmeir, 2022).
