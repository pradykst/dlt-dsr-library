# Design objective Objective 5: Privacy

Protecting customers' privacy is a key feature of an eKYC process. An essential and fairly universal principle in this context is compliance with the "need to know" principle: only the customers themselves and entities relevant to the KYC process must have access to customers' personal data. Further, the parties involved and the de facto data exchanged should be restricted to what is necessary, a requirement called data minimization.

## Source paper

This design objective is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
