# Design objective DO9: Web-interface key management

The KYC-system should allow key management facilitated via a web interface; proper incentives for investors need to be set.

## Source paper

This design objective is proposed by [Know-Your-Customer (KYC) Requirements for Initial Coin Offerings: Toward Designing a Compliant-by-Design KYC-System Based on Blockchain Technology](../papers/kyc-ico-requirements.md) (Nadine Kathrin Ostern, Johannes Riedel, 2021).
