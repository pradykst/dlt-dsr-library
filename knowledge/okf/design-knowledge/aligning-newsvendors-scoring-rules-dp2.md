# Design principle DP2: Enforceable and immutable algorithmic contracts

Contracts between the newsvendor and the expert should be defined as enforceable and immutable algorithms. One can code a contract between a newsvendor and an expert as a smart contract - an algorithm stored in the blockchain whose source code is immutable - which fulfills this design principle.

## Source paper

This design principle is proposed by [Aligning the interests of newsvendors and forecasters through blockchain-based smart contracts and proper scoring rules](../papers/aligning-newsvendors-scoring-rules.md) (Arthur Carvalho, Majid Karimi, 2021).
