# Design requirement DR3: New nodes can join later

It should be possible for new nodes to join the network afterwards. The paper's evaluation later reports that this requirement was not fully met.

## Source paper

This design requirement is proposed by [Design of a forgetting blockchain: A possible way to accomplish GDPR compatibility](../papers/forgetting-blockchain-gdpr.md) (Simon Farshid, Andreas Reitz, Peter Roßbach, 2019).
