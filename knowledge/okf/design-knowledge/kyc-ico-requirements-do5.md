# Design objective DO5: Correction of inaccurate data

An ICO investor must have the opportunity to ask for the correction of inaccurate data. To this end, data captured during the blockchain-based KYC-process need to be stored in a way that allows for revocation.

## Source paper

This design objective is proposed by [Know-Your-Customer (KYC) Requirements for Initial Coin Offerings: Toward Designing a Compliant-by-Design KYC-System Based on Blockchain Technology](../papers/kyc-ico-requirements.md) (Nadine Kathrin Ostern, Johannes Riedel, 2021).
