# Design objective DO3: Allow for concurrent document processing

As process participants do not need to wait for paper-based documents to arrive, a concurrent document check is possible for the advising and issuing bank.

## Source paper

This design objective is proposed by [Cross-Organizational Workflow Management Using Blockchain Technology - Towards Applicability, Auditability, and Automation](../papers/cross-org-workflow-objectives.md) (Gilbert Fridgen, Nils Urbach, Sven Radszuwill, Lena Utz, 2018).
