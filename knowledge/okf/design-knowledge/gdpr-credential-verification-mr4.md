# Meta-requirement MR4: Data-protection conformance

The verification system should conform to available data-protection and privacy regulations so that data ownership and access control are ensured.

## Source paper

This meta-requirement is proposed by [Designing GDPR Compliant Credential Verification Using Blockchain: A Design Science Research Approach](../papers/gdpr-credential-verification.md) (Janne Parkkila, AKM Bahalul Haque, Jaakko Vuolasto, Anastasiia Gurzhii, Sami Hyrynsalmi, Najmul Islam, 2024).
