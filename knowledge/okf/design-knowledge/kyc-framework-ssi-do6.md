# Design objective Objective 6: User experience

From the users' perspective, the most important objective is seamless user experience. The eKYC process must be convenient, so low complexity is a major requirement. The variety of devices customers use must be respected, so the availability of different user interfaces is important. The user experience should also include exception handling, such as backup, recovery, and support if a device is lost or stolen.

## Source paper

This design objective is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
