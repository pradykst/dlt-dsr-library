# Design requirement R1.2: Automation of manual processes

In the current KYC process, many steps involving the validation of data, such as checking whether an ID document's validity has expired, are conducted manually. Thus, the de facto automation of manual processes is another key requirement.

## Source paper

This design requirement is proposed by [Designing a Framework for Digital KYC Processes Built on Blockchain-Based Self-Sovereign Identity](../papers/kyc-framework-ssi.md) (Vincent Schlatt, Johannes Sedlmeir, Simon Feulner, Nils Urbach, 2022).
